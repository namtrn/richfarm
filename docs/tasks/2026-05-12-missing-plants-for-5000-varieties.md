## Technical Notes

### Required Data for Each Plant
- `scientificName` (required)
- `genus`, `species`, `cultivar` (taxonomy)
- `group` (business category)
- `commonName` (en, vi, es, pt, fr, zh)
- `description` (optional)
- `family`
- `purposes` (array)
- `care data` (typicalDaysToHarvest, spacingCm, etc.)

### Import Workflow
1. Create source data file (CSV/JSON)
2. Transform to match schema format
3. Add to `plantI18nSource/*.json`
4. Regenerate seed files via scripts
5. Test import to Convex
